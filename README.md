## 📖 Overview

**Layered Society** is a 4-layer agent-based sandbox where digital citizens survive, evolve, believe, and interact. Driven by emergent, bottom-up behavior rather than scripted rules, the simulation explores what happens when misinformation collides with survival pressure, evolution, and social structure.

Each agent possesses its own neural network to make survival decisions (moving, foraging). Populations evolve across generations through mutation and natural selection. 

In this ecosystem, covert **Sleeper Agents** inject misinformation into the belief network. An adaptive defense algorithm (SW-MSR) responds in real-time, tightening or loosening moderation based on social cohesion. Under extreme pressure, agents may defect into open rebellion or betray their own factions.

An unsupervised machine learning pipeline then attempts to detect these Sleeper Agents purely from behavioral fingerprints, benchmarked against simpler baselines.

## 🏗️ The 4-Layer Architecture

The simulation is built on a robust 4-layer architecture, each modeling a critical aspect of society:

| Layer | System | What it models | Key Mechanism |
| :---: | :--- | :--- | :--- |
| **0** | **Environment** | Physical space, resource scarcity, and dynamic events (e.g., droughts). | Agents must forage energy to survive. The environment dictates survival pressure. |
| **1** | **Neural Brain & Evolution** | Individual decision-making and genetic progression. | Small MLP per agent. Reproduction and mutation occur when agents surpass an energy threshold. |
| **2** | **Belief Engine & Factions** | Belief updates and misinformation propagation. | Log-Likelihood Ratio (LLR) updates. Sleeper Agents inject false narratives. Adaptive SW-MSR defense mitigates spread. |
| **3** | **Social Graph & Extremism** | Network structure, societal cohesion, and emergent extremism. | Rebellion (belief > 0.85 + energy < 35); Betrayal (5% defection chance at energy < 25). |

### 🛡️ Adaptive Defense (SW-MSR)

Instead of a static moderation threshold, the filtering parameter `f` adapts dynamically to the rate of change of social cohesion:

```math
f(t+1) = \text{clamp}(0.05, 0.40, f(t) + \lambda \cdot \frac{d(\text{Cohesion})}{dt})
```

Filtering tightens as society polarizes and relaxes as it stabilizes—mirroring real-world algorithmic moderation and governance.

## 🤖 Sleeper Agent Detection (ML Pipeline)

Using large-scale, multi-seed synthetic behavioral data generated by the simulation, three anomaly-detection approaches were evaluated to identify Sleeper Agents with **zero labels** at training time:

| Detection Method | Precision | Recall | F1 Score |
| :--- | :---: | :---: | :---: |
| **Rule-based heuristic** | 0.46 | 0.86 | **0.60** |
| **Isolation Forest** | 0.38 | 0.43 | 0.40 |
| **One-Class SVM** | 0.12 | 0.14 | 0.13 |

> **Key Insight:** A simple heuristic baseline currently outperforms standard one-class ML methods under low-sample, low-prevalence conditions. See the [`research/`](./research) directory for the full evaluation pipeline and deeper analysis.

## 🚀 Quick Start

### 1. Simulation Engine (Frontend)
Run the real-time agent simulation, physics, and rendering.

```bash
# Clone the repository
git clone https://github.com/your-username/layered-society.git
cd layered-society

# Install dependencies
npm install

# Start the development server
npm run dev
```

### 2. Analysis & ML Pipeline (Backend)
Run the data visualization and AI anomaly detection models.

```bash
# Navigate to the research directory
cd research

# Install Python requirements
pip install -r requirements.txt

# Run the pipeline
python 01_data_visualization.py
python 02_ai_sleeper_detection.py
```
